# Language

[Back to root README](../README.md)

This directory contains language-specific learning material, exercises, and small practice projects.

## Structure

```text
language/
|-- dotnet/
`-- python/
```

## Contents

- `dotnet/` - .NET and C# learning material.
- `python/` - Python basics, exercises, problems, and challenges.

## Guidelines

- Add new language learning material under a dedicated language folder.
- Keep language-specific notes and setup instructions inside that language folder.
- Use the prototype repository for experiments that are not primarily learning notes or exercises.
