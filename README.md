# Learning

This repository is a personal learning space for trying out new languages, frameworks, libraries, tools, and concepts in a structured way.

- Keep learning notes, exercises, course work, and small practice projects here.
- Use the dedicated area READMEs for detailed navigation:
  - [Language](language/README.md)
  - [Framework](framework/README.md)
- Keep experiments and prototype-style work in the separate prototype repository instead of this repo.
- Prefer organizing new learning material under the closest matching top-level folder.

## Organization

- `language/` contains language-specific learning material and practice projects.
- `framework/` contains framework, library, and ecosystem-specific learning material.
