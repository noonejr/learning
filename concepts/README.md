# Concepts

[Back to root README](../README.md)

This directory contains concept-focused learning projects, each a self-contained `uv` project.

## Structure

```text
concepts/
|-- agent-harness/
`-- nano-gpt-lecture/
```

## Contents

- `agent-harness/` - agent harness project scaffold (`src/agent_harness/`, `env.example`).
- `nano-gpt-lecture/` - nano GPT lecture notebook (`lecture.ipynb`).

## Guidelines

- Add each new concept under a dedicated folder with its own setup and notes.
- Use the prototype repository for experiments that are closer to product prototypes or proof-of-concept work.
